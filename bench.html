What is being checked. A monochromatic Ks,t in color c is s vertices against t other vertices with every one of the s·t edges between them in color c. Nothing is required of the edges inside either set. A clique Kk is k vertices with all internal edges one color.

The two view toggles. On the grid a clique is a square straddling the diagonal, because the same vertices index rows and columns. A complete bipartite subgraph is an off-diagonal rectangle instead — but only when its rows and columns happen to be adjacent, and the tightest sets usually carry scattered labels. Align to block permutes the axes to gather them, so the rectangle becomes contiguous and gets outlined; relabeling vertices never changes an edge's color, so it is the same object seen from a better angle. Keep the original order to read global structure instead — a circulant's diagonal banding exists only in that numbering and disappears under any reordering. Highlight is independent of both: turn it off to see the raw coloring at full contrast.

Bipartite cases are decided by counting common neighborhoods, which is equivalent to enumerating placements and far cheaper; cliques are enumerated directly. Stepping through the highlights walks the tightest configurations — the sets that come closest to forcing the forbidden graph without doing so.
